# Nexus Client v1.0.0

Witaj w pierwszym wydaniu **Nexus Client**! Jest to zupełnie nowa odsłona i oficjalna premiera aplikacji (wersja 1.0.0), przygotowana z myślą o płynnej i bezproblemowej rozgrywce w Minecrafta. Poniżej znajduje się zestawienie kluczowych funkcji oraz usprawnień dostępnych w tym wydaniu.

---

### Główne cechy i funkcje

* **Pełne wsparcie dla Minecrafta 26.3:** Klient został w pełni zaktualizowany, zapewniając pełną kompatybilność i stabilne działanie z najnowszą wersją gry.
* **Zaawansowany system instancji:** Obsługa wielu niezależnych instancji gry z odseparowanymi plikami dla każdej z nich (w folderze `%APPDATA%/.nexus-client/instances/`).
* **Obsługa wielu silników:** Wbudowane wsparcie dla silników **Vanilla**, **Fabric** oraz **Forge**.
* **Automatyczne zarządzanie środowiskiem:**
* Automatyczne pobieranie i dopasowywanie odpowiedniej wersji Javy (Adoptium) do danej wersji gry.
* Inteligentna synchronizacja i pobieranie modów bezpośrednio z platformy **Modrinth**.
* Automatyczna synchronizacja konfiguracji z repozytorium GitHub oraz pobieranie paczek zasobów (*resourcepacks*).


* **Inteligentne auto-naprawy:** Wbudowane mechanizmy naprawcze m.in. dla uszkodzonych plików, błędnych opcji JVM, konfliktów modów (np. Fabric API ↔ YACL) oraz automatyczne czyszczenie i zarządzanie modami Iris i Sodium.

### Poprawki i ulepszenia w wersji 1.0.0

* **Mechanika skinów:** Poprawiono stabilność ładowania oraz poprawne wyświetlanie skinów graczy.
* **Interfejs logowania:** Usprawniono działanie i wyeliminowano napotkane wcześniej problemy na wybranych ekranach logowania.
* **Stabilność i wydajność:** Wprowadzono szereg optymalizacji w procesie uruchamiania gry przez Electrona oraz CLI, a także udoskonalono system obsługi logów błędów.
